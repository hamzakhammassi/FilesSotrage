# Script de tri iCloud (PowerShell)

Ce projet contient un script PowerShell permettant de trier et organiser des fichiers provenant d’iCloud Photos.

## Prérequis
- Windows avec PowerShell installé
- Droits d’exécution des scripts PowerShell activés

## Utilisation

1. Ouvrir un terminal PowerShell
2. Aller dans le dossier du script :

```powershell
cd C:\Users\hamza\Documents\project\FilesSotrage\src\main\resources
```

## Exécution du script

Lancez la commande suivante dans PowerShell :

```powershell
.\sort-icloud.ps1 -SourcePath "C:\Users\hamza\Downloads\test\PhotosiCloud\PhotosiCloud"
```
